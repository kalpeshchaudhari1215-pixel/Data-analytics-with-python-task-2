# Data-analytics-with-python-task-2
Titanic Dataset Analysis This project is part of my Data Science with Python Internship – Task 2.

### Objective

The objective of this task is to analyze the Titanic dataset and identify survival patterns among passengers.

### Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* Kaggle Titanic Dataset

### Tasks Performed

* Loaded the Titanic dataset
* Explored the dataset
* Checked missing values
* Cleaned missing values
* Analyzed survival by gender
* Analyzed survival by passenger class
* Analyzed survival rate by age group
* Created a survival-by-gender bar chart
* Created a survival-by-class bar chart
* Created a passenger-age histogram

### Key Findings

* Female passengers had a higher survival rate than male passengers.
* Passenger class had an impact on survival.
* First-class passengers had a higher survival rate than third-class passengers.
* Survival patterns were also analyzed across different age groups.
